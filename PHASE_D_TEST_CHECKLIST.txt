-----------------------------
1) Leave Local echo OFF.
2) Send a valid command/payload that succeeds over the active BLE write characteristic.
3) Filter Category = TX_RAW or Direction = TX.

Expected:
[ ] Successful TX creates one TX_RAW structured entry
[ ] TX_RAW contains byte length and HEX representation
[ ] TX_RAW is present even though Local echo is OFF
[ ] Main TX byte counter increases normally

Failure behavior:
1) Produce a write failure if safely/reproducibly possible, for example by disconnecting
   before sending or using a non-writable state.

Expected:
[ ] Failed send is NOT reported as a successful TX_RAW entry
[ ] Existing terminal error handling remains visible
[ ] ERROR filter can surface the failure when the terminal emits an error event
