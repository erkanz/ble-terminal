BLE SERIAL TERMINAL - RT950 MANUAL GATT TX TEST CHECKLIST
========================================================
Date created: 2026-09-06
Scope: BLE Serial Terminal application only
Firmware changes: NONE
APRSdroid changes: NONE
Radio firmware/code changes: NONE

PURPOSE
-------
Verify the RT-950 Pro host-to-radio GATT write path independently on FFE1 and FF31 while preserving the already-qualified FFE1 notification/KISS RX path.

IMPORTANT RESULT LANGUAGE
-------------------------
A successful Windows GATT write means only that the Windows BLE stack reports the GATT operation as successful.
It does NOT prove that the RT-950 transmitted RF or accepted an OEM command at the radio-application layer.
An OEM response/ACK received on FFE1 is separate evidence.

-------------
[ ] Use the newest successful GitHub Actions artifact from main.
[ ] RT-950 Pro powered on and BLE available.
[ ] Auto detect BLE-UART GATT profile remains enabled.
[ ] Connect to the RT-950 and wait for the normal RT950 readiness chain.

[ ] FFE1 NOTIFY ACTIVE
