# Windows builds

Windows x64 builds are generated by GitHub Actions from the exact source committed to this repository.

- Every push to `main`: self-contained single-file `BLESerialTerminal.exe` is available under **Actions > Build Windows EXE > Artifacts**.
- Manual builds: run the same workflow with **Run workflow**.
- Version tags matching `v*`: the EXE and SHA-256 checksum are also attached to a GitHub **Release**.

The generated EXE is intentionally not committed back into Git history. GitHub Actions artifacts and Releases are the canonical binary store, so every build remains traceable to its source commit.
